## 1. Core Hypothesis & Objective

Evaluate strictly causally whether E4's most robust predictive capacities:
- `Late Entry Risk` (prior validation AUC ≈ 0.8294)
- `Tail Risk` (prior validation AUC ≈ 0.7319)

can function effectively as **post-signal entry guards/critics** on trades already generated by Aegis Turbo, without altering Aegis's directional decision (`ALLOW` vs `BLOCK` only).

The central empirical question is:
> *Did E4 entry guards block sufficient bad trades and tail losses to economically improve Aegis's net expectancy, profit factor, and drawdown without destroying disproportionate winning trades?*

## 4. Evaluated Guard Policies

1. **Policy A (`AEGIS_ONLY`)**: Baseline. Execute 100% of Aegis signals.
2. **Policy B (`AEGIS_PLUS_LATE_ENTRY_GUARD`)**: Block if `e4_late_entry_score >= 0.037697` (Q70 calibrated).
3. **Policy C (`AEGIS_PLUS_TAIL_RISK_GUARD`)**: Block if `e4_tail_risk_score >= 0.452245` (Q70 calibrated).
4. **Policy D (`AEGIS_PLUS_E4_DUAL_GUARD`)**: Block if `e4_late_entry_score >= 0.037697` OR `e4_tail_risk_score >= 0.452245`.

---

## 5. Cost Scenarios & Evaluation Metrics

- **Cost Scenarios**: 0 bps, 14 bps (Primary), 20 bps (Conservative), 30 bps (Stress).
- **Core Metrics**:
  - `Net Guard Value (bps)` = Loss Avoided - Profit Destroyed + Fees Avoided.
  - `Loss Saved per Profit Destroyed Ratio` = Loss Saved / Profit Destroyed.
  - `Net Expectancy per Executed Trade (bps)`.
  - `Bad Trade Rejection Rate (%)` vs `Good Trade Destruction Rate (%)`.
  - `Tail Loss Rejection Rate (%)`.
  - `Profit Factor`, `MFE/MAE Ratio`, `Max Drawdown (bps)`.
