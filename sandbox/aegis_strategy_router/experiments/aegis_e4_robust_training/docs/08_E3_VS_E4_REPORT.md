# Frozen E3 Versus E4

E3 remains frozen. Its official four economic validation folds were all
negative: approximately -19.1, -18.4, -11.0 and -11.1 bps in the source
report's return units converted to bps. E3 is SHORT-trained and used 172,480
rows from 15,680 hourly cycles with 83 features.

An exact head-to-head score comparison is not valid because E3 and E4 labels,
periods and side populations differ. This report therefore uses:

1. the frozen official E3 report as historical baseline; and
2. a controlled E3-like BASE model trained on hourly anchors and evaluated on
   the same E4 labels.

E4 improves causal realism, cadence alignment and calibration. It also predicts
MFE/MAE magnitudes better than a constant baseline. It does not produce a
material favorable-first advantage or economic improvement. More features did
not rescue the directional bottleneck.
